# Claude Certification Mock Exams

Interactive practice exams for the current Anthropic Claude
certification suite.

> **Disclaimer**
>
> These mock exams are **community-created learning resources**. They
> are **not affiliated with, endorsed by, or produced by Anthropic**,
> and they do **not** contain real exam questions.

## Available Mock Exams

  Certification                                           Questions      Time
  ----------------------------------------------------- ----------- ---------
  Claude Certified Architect -- Foundations (CCAR-F)             60   120 min
  Claude Certified Architect -- Professional (CCAR-P)            63   120 min
  Claude Certified Developer -- Foundations (CCDV-F)             53   120 min
  Claude Certified Associate -- Foundations (CCAO-F)             60   120 min

## Features

-   Timed **Exam Mode**
-   **Study Mode** with instant feedback
-   Detailed explanations for every answer
-   Domain-by-domain score breakdown
-   Questions aligned to the published certification objectives
